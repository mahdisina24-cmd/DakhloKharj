# دخل‌وخرج — اپلیکیشن اندروید

اپلیکیشن مدیریت مالی شخصی با رابط فارسی، ذخیره‌سازی محلی SQLite و پشتیبان‌گیری JSON.

## امکانات
- داشبورد موجودی، درآمد و هزینه ماه جاری
- ایجاد، ویرایش و حذف درآمد، هزینه و انتقال بین حساب‌ها
- مدیریت حساب‌ها و دسته‌بندی‌ها
- انتقال بدون محاسبه به عنوان درآمد یا هزینه
- گزارش‌های ساده و نمودارهای میله‌ای
- نمایش تاریخ شمسی؛ تاریخ در دیتابیس به قالب ISO ذخیره می‌شود
- پشتیبان‌گیری و بازیابی JSON
- دیتابیس SQLite محلی؛ بدون نیاز به حساب کاربری یا کلید محرمانه

## اجرا
نیاز به Node.js LTS و npm دارد:
```bash
npm install
npx expo start
```
Expo Go را روی گوشی اندروید نصب کن و QR کد ترمینال را اسکن کن.

## ساخت APK
برای ساخت ابری با EAS:
```bash
npx eas-cli@latest build:configure
npx eas-cli@latest build --platform android --profile preview
```
در صورت درخواست حساب Expo، در expo.dev حساب بساز. رمز و کلیدهای محرمانه را در GitHub commit نکن.

## حریم خصوصی
اطلاعات در SQLite روی همان گوشی ذخیره می‌شود. با حذف اپ ممکن است دیتابیس پاک شود، پس فایل JSON پشتیبان را در محل امن نگه دار. این نسخه احراز هویت یا همگام‌سازی ابری ندارد چون ذخیره‌سازی محلی انتخاب شده است.
