# دخل‌وخرج — نسخه نهایی اندروید

**نسخه:** 1.1.0 (Final)  
**سازنده:** Mahdi Eskandari  
**پلتفرم:** Android  
**شناسه برنامه:** `com.mahdisina24.dakhlokharj`

اپلیکیشن مدیریت مالی شخصی با رابط فارسی و تاریخ شمسی، برای ثبت و پیگیری درآمدها، هزینه‌ها، حساب‌ها، بدهی‌ها، اقساط و چک‌ها. داده‌ها به‌صورت محلی در SQLite روی دستگاه نگهداری می‌شوند.

## امکانات

- داشبورد خلاصه موجودی، درآمد و هزینه
- ثبت، ویرایش و حذف تراکنش‌های درآمد، هزینه و انتقال بین حساب‌ها
- مدیریت حساب‌ها و دسته‌بندی‌ها
- گزارش‌های مالی و فیلتر بر اساس دوره و نوع تراکنش
- تقویم و نمایش تاریخ شمسی؛ ذخیره تاریخ‌ها در دیتابیس با قالب میلادی ISO
- مدیریت چک، بدهی و اقساط
- ثبت جهت چک به‌صورت «چک دریافتی از دیگران» یا «چک صادرشده»
- وضعیت‌های چک: «وصول شده»، «در جریان»، «خوابیده»، «در حساب» و «برگشت خورده»
- یادآوری محلی چک در ساعت ۹ صبحِ روز قبل از سررسید، با نمایش عنوان و مبلغ
- اعلان‌ها نیاز به اجازه کاربر دارند؛ یادآوری چک‌های وصول‌شده، تسویه‌شده یا برگشت‌خورده ارسال نمی‌شود
- پشتیبان‌گیری و بازیابی اطلاعات در قالب JSON
- قفل برنامه با PIN و پشتیبانی از احراز هویت زیستی در دستگاه‌های سازگار

## ثبت چک دریافتی

به بخش «چک و قسط» برو، گزینه «افزودن» را بزن و نوع را روی «چک» و جهت را روی «چک دریافتی از دیگران» تنظیم کن. عنوان، مبلغ و تاریخ سررسید را وارد کن و ذخیره کن. برای دریافت اعلان، مجوز اعلان‌های برنامه را در گوشی تأیید کن.

## اجرای پروژه در محیط توسعه

نیاز به Node.js نسخه LTS و npm دارد:

```bash
npm install
npm run typecheck
npx expo start
```

## ساخت APK

از مخزن GitHub، بخش **Actions** و گردش‌کار **Build Android APK** را باز کن. پس از موفقیت ساخت، فایل APK در بخش **Artifacts** همان اجرا قرار می‌گیرد. گردش‌کار APK برای مدت محدود artifact را نگه می‌دارد.

برای ساخت دستی در محیط توسعه:

```bash
npm install
npx expo prebuild --platform android
cd android
./gradlew assembleRelease
```

## حریم خصوصی و پشتیبان‌گیری

اطلاعات مالی در دیتابیس SQLite روی همان دستگاه ذخیره می‌شوند و این برنامه برای عملکرد معمول به حساب کاربری یا همگام‌سازی ابری نیاز ندارد. فایل پشتیبان JSON را به‌صورت دوره‌ای در محل امن نگه دار؛ حذف برنامه یا پاک‌کردن داده‌های آن ممکن است اطلاعات محلی را از بین ببرد.
