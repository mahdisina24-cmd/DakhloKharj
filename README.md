# دخل‌وخرج | مدیریت مالی شخصی

یک برنامه سبک، فارسی و راست‌چین برای ثبت درآمد و هزینه، مشاهده موجودی و گرفتن خروجی CSV.

## امکانات
- ثبت درآمد و هزینه با عنوان، مبلغ، دسته‌بندی و تاریخ
- نمایش موجودی کل، مجموع درآمد و مجموع هزینه
- جست‌وجو و فیلتر تراکنش‌ها
- نمایش تاریخ به تقویم شمسی
- خروجی CSV برای استفاده در صفحه‌گسترده‌ها
- ذخیره محلی اطلاعات در مرورگر با `localStorage`
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای انتشار رایگان می‌توانید در تنظیمات مخزن، از بخش **Settings → Pages**، شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.

## نکته درباره حریم خصوصی
این نسخه اطلاعات را در حافظه محلی همان مرورگر ذخیره می‌کند؛ داده‌ها به سرور ارسال یا بین دستگاه‌ها همگام‌سازی نمی‌شوند. پاک‌کردن داده‌های مرورگر ممکن است اطلاعات ذخیره‌شده را حذف کند، بنابراین از خروجی CSV پشتیبان بگیرید.

## فناوری‌ها
HTML، CSS و JavaScript خالص؛ بدون نیاز به نصب وابستگی.
